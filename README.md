# 云服务器购买：从选配置到下单付款的完整流程，新手也能避开办案、带宽和续费三大坑

搜"云服务器购买"的人，基本逃不出三种状态：一种是连 CPU 和内存分别干什么都不清楚，想找人先讲一遍；一种是参数看懂了，但在价格表、线路名和"原价/活动价"之间绕晕；还有一种只用过一家的机器，现在想换台更便宜、线路更好的。

这三种状态的共同点是：真正的问题不在"哪家便宜"，而在"我该买哪一档，以及买完之后会不会被续费价和流量费再割一刀"。下面按实际的购买顺序讲一遍，参数、价格和坑都放在该出现的位置。

## 先想清楚三件事，再去点"立即购买"

配置买大了是浪费，买小了是折磨，判断依据只有三个问题。

**第一，跑什么。** 静态博客和跑数据库的 Java 服务，对 CPU 和内存的要求完全不是一个量级。

**第二，谁在访问。** 访客在国内，香港、日本、韩国节点比美国西海岸稳；访客在海外，就近选节点。这里的关键不是带宽数字，而是线路——CN2、CMI、优质 BGP 和普通国际带宽，晚高峰的差别能到十倍。

**第三，跑多久。** 临时测试可以按量付费甚至用试用；长期挂着就得看年付折扣和续费价，这一步最容易被忽略。

按这三条落下来，配置大概是这样：

| 用途 | 建议配置 | 说明 |
| --- | --- | --- |
| 学习、练手、测试 | 1 核 1G | 能跑通环境就行，别多花钱 |
| 个人博客、静态站 | 1 核 1G ～ 2 核 2G | 日均几百 PV 足够 |
| WordPress / 小型动态站 | 2 核 2G ～ 2 核 4G | 内存比 CPU 更容易先不够 |
| 企业官网、小程序后端 | 2 核 4G ～ 4 核 4G | 留出数据库和并发余量 |
| 电商、论坛、中型应用 | 4 核 8G 以上 | 带宽往往比 CPU 先到瓶颈 |
| 游戏服务器（Minecraft 等） | 高主频 2 核 4G 起 | 吃单核性能，不吃核心数 |

## 五个参数：哪些是硬指标，哪些只是营销词

### CPU：核心数不等于性能

"2 核"背后可能是独占的物理核心，也可能是高比例超卖切出来的 vCPU。同样写 4 核 8G，一台 32 核母机可以切 64 个实例，也可以切 128 个，你拿到的真实算力差一倍。买之前值得确认两件事：**CPU 型号和主频**、**是否低超卖**。

对大多数 Web 场景，单核主频比核心数更有用。雨云的游戏云机型用 i9-13900KF / 14900K、Ryzen 7950X 这类桌面级高主频 CPU，并且屏蔽小核，就是冲着单核性能去的。

### 内存：估算时多留 50%

内存不够会频繁走 swap，用硬盘当内存，性能断崖式下跌。跑 WordPress+MySQL，2G 是能跑但紧张，4G 才舒服。容量建议按当前需求往上留一档，但别为"以后可能用到"提前买三年。

### 带宽与流量：这是最常见的账单陷阱

带宽是瞬时速率，流量是累计传输量，两者混着看就会踩坑。

| 带宽 | 理论峰值速度 | 大致适用 |
| --- | --- | --- |
| 1 Mbps | 0.125 MB/s | 测试、极小站 |
| 5 Mbps | 0.625 MB/s | 企业官网、小型 WordPress |
| 10 Mbps | 1.25 MB/s | 普通内容站 |
| 50 Mbps | 6.25 MB/s | 图片站、中等流量站 |
| 100 Mbps | 12.5 MB/s | 流量较大的业务站 |
| 1 Gbps | 125 MB/s | 大带宽、高并发场景 |

换算是 1 Byte = 8 bit。注意这是理论峰值，实际还要扣掉线路质量、用户距离和 TCP/TLS 开销。

更需要留意的是"不限流量"和"限流量"两种模式。限流量的套餐，流量超了通常会被限速（雨云部分线路是限到 1M 或 5M），想恢复速度得单独买流量包——比如韩国线路的额外流量按 20G/20 元、100G/100 元、200G/180 元充值。不限流量的套餐，通常上行带宽会小一些，价格也可能差一截。

### 硬盘：SSD 是底线

系统盘至少选 SSD，跑数据库优先 NVMe。机械盘只适合放备份和冷数据。容量上，雨云多数套餐的系统盘可以弹性扩容，价格按 GB/月计（不同线路 0.1～0.4 元/GB/月不等），不必一开始就买满。

### 线路与地域：决定了"能用"和"好用"的距离

这是国内用户最该花时间的一项。同样是"香港节点"，三网优化的 CN2/CMI 线路和纯国际线路，晚高峰体验完全不同。判断方法很笨但有效：问清是否大陆优化、去程和回程各走哪家运营商，然后在晚上八点到十一点自己 ping 和 mtr 一次。

## 计费模式和备案：两个下单前必须确认的前提

**包年包月**是先付费后使用，单价最低，适合 7×24 长期运行的服务。**按量付费**按小时或按秒结算，适合临时扩容和测试，但单价高，忘释放会一直扣费。**抢占式实例**最便宜，可能因市价或库存被系统回收，只适合无状态、能容忍中断的任务，新手别碰。

备案这一项，很多人是买完才发现。简单说：香港、日本、美国、韩国、德国等境外节点做网站不需要 ICP 备案；中国大陆节点要备案，而且通常要求购买时长不少于 3 个月才给备案服务号（各地要求有差异，以实际页面为准）。如果你就是不想折腾备案流程，那选香港或日本节点最省事。

## 购买流程：从注册到能登录，一共六步

1. **注册并完成认证。** 手机号或邮箱注册，按要求完成实名。
2. **进购买页选区域。** 雨云的区域覆盖美国洛杉矶、日本东京、中国香港、韩国首尔、德国法兰克福，以及国内的广东深圳、湖北十堰、江苏宿迁、浙江温州/绍兴/宁波、江苏镇江、重庆等。
3. **选配置档位。** 先定 CPU 和内存，再确认硬盘容量。
4. **选系统镜像。** 可以选纯净的 Linux/Windows 镜像，也可以直接选预装宝塔、1Panel 这类面板的环境镜像，省掉装环境的时间。雨云支持 Docker、Java 环境，也支持一些常见应用的一键部署。

## 避坑清单：买之前逐条对一遍

**只看首年价，不看续费价。** 很多促销是首单专属，第二年按原价续。买之前把"月付原价、续费价、带宽续费、硬盘续费、IP 是否另收费"五项都问清楚。雨云的长期折扣是按季付/半年付/年付的档位给的，可预期性相对好一些。

**带宽数字大，但可能是共享。** 100Mbps、1Gbps 写得很好看，实际可能是共享端口，忙时明显掉速。确认清楚是独享带宽、峰值带宽还是共享带宽。

**限流量的套餐，只看到手价。** 流量超了被限速，业务会直接瘫。选之前先按"日 PV × 页面大小 × 图片和下载量"估一下月流量，再确认超额单价和限速阈值。

**被"不限流量"四个字迷惑。** 部分线路的不限流量套餐上行带宽更小，价格也和美国、香港的流量叠加型不是一个档位，横向比价时要对齐口径。

**下单前忘了算 IP 和高防。** 香港、韩国等区域的月付价通常不含 IPv4，普通 IP 约 5 元/月，原生 IP 10 元/月，住宅 IP 25 元/月。做跨境业务需要原生或住宅 IP 的，别等买完才发现账单对不上。

## 什么情况下适合选雨云，什么情况下不适合

雨云成立于 2018 年，是家国产云计算服务商，持有工信部颁发的 ISP、IDC、CDN 证，财务和产品系统自研。第三方测评里能看到一些硬件实拍数据，比如德国法兰克福 2 核 4G（AMD EPYC 7452）在 Geekbench 6 上跑出单核 1125、多核 2001——这类数据来自社区测评帖，只能作为硬件水平的大致参考，不代表你买到的那台机器的实际表现。

比较适合它的场景：预算敏感的个人开发者和学生、需要多条国内/境外线路做测试或建站、要开 Minecraft 类高主频游戏服、以及需要原生 IP 或住宅 IP 做跨境业务的用户。区域覆盖广、档位多、支持 1 元试用和 7 天退款，试错成本低是它的主要优势。

不太适合的场景：需要企业级 SLA 承诺、等保合规、专线接入或大规模集群调度的业务。这类需求应该去找能签合同、给明确可用性承诺的厂商，几十块一个月的虚拟化实例解决不了。

最后回到最初那个问题——云服务器购买这件事的难点从来不是"哪家最便宜"，而是把需求、线路、计费方式和续费成本这四件事对齐。对齐了，你花 25 元/月买的机器能稳定跑三年；没对齐，花 200 元/月照样会出问题。
